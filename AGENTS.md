# Public profile edits

Keep the writing direct and specific. Use the Google developer documentation
style guide as a reference; favor short sentences and consistent terms. Do not
claim ASD-STE100 compliance. Preserve the illustrated cards and terminal header.

Before publishing, review the exact diff, commit metadata, linked destinations,
and new assets for secrets and personal information. Inspect visible image
content and embedded metadata. Do not copy private project names, local paths,
customer records, contact details, or private logs into this repo. Use the public
GitHub handle and a GitHub noreply address for commits. Pattern scans support
review; they do not prove that content is safe.

Describe experiments with their limits. Link results to evidence, and do not
turn usage statistics into performance claims. Check the rendered GitHub profile
after changing its layout, images, or links.
