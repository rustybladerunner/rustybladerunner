## About

<div align="center">
  <img src="assets/terminal-bio.svg" alt="Terminal bio" width="800" />
</div>

<br/>

I build systems that run on **your** machine instead of someone else's cloud — research daemons, generative pipelines, games, and desktop tools. Personal data never leaves the box; cloud models are for non-personal research only.

The constraint I design around is a single **8 GB consumer GPU** (RTX 3060 Ti). Not a limitation to engineer away — the budget that decides the architecture.

Fifteen projects in rotation. Most ship under production codenames — the way a film shoots under a fake name — until they are ready to be named. The public surface is the portfolio and the four originals below.

Anyone can rent the same model. What compounds is the scaffolding: specs as truth, typed memory, and back pressure that fails the build when an agent drifts. **16 of 19 gates** ship with a paired self-test that feeds the gate a violation and asserts it refuses. The three without one are named in the backlog rather than quietly counted as passing.
